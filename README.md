# Sistema de Gerenciamento de Projetos de Extensão

Sistema web para gerenciamento de projetos de extensão universitária desenvolvido como projeto acadêmico.

## Funcionalidades

- Cadastro de usuários e bolsistas
- Gerenciamento de projetos de extensão
- Administração de cursos
- Geração de relatórios em PDF
- Painel administrativo

## Tecnologias

- PHP
- MySQL
- HTML/CSS
- JavaScript
- FPDF (geração de PDFs)

## Como Executar

1. Configure um servidor local (XAMPP, WAMP ou similar)
2. Importe o banco de dados `banco.sql`
3. Configure a conexão em `conn.php`
4. Acesse via navegador
